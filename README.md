# 🔍 Testing Approach

1. Understand requirements
2. Identify users, roles and critical flows
3. Define scope and risks
4. Prepare test data
5. Create test cases and checklists
6. Execute positive and negative scenarios
7. Explore edge cases
8. Document defects
9. Retest fixes
10. Report test results
