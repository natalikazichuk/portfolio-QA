# BUG-UI-001 — Незрозуміла назва категорії «Всі сектори»

## Title
Незрозуміла назва категорії «Всі сектори» у фільтрі вакансій

## Environment
- Platform: VeteranJobPortal
- Module: Job Search
- Component: Category filter
- Browser: Chrome
- OS: Windows

## Preconditions
Користувач відкрив сторінку пошуку вакансій.

## Steps to Reproduce
1. Відкрити сторінку пошуку вакансій.
2. Відкрити фільтр категорій.
3. Знайти опцію «Всі сектори».
4. Спробувати визначити, які категорії вакансій входять до цієї опції.

## Actual Result
Назва «Всі сектори» є недостатньо зрозумілою для користувача. Незрозуміло, чи означає вона всі категорії вакансій, чи окремий сектор.

## Expected Result
Назва категорії повинна однозначно передавати її призначення. Наприклад:
- «Усі категорії»
- «Всі категорії вакансій»

За потреби можна додати tooltip/пояснення.

## Severity
**Minor**

## Priority
**Medium**

## Type
**UI/UX — Usability**

## Impact
Користувач може неправильно зрозуміти призначення фільтра та обрати неправильний варіант під час пошуку вакансій.
